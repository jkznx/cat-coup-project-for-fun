# Cat Coup
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Confirmed: React and TypeScript client, Node.js and Socket.IO server.

## Product Purpose
Play a cat-character adaptation of Coup online with friends using room codes.

## Users
Players joining the same room from separate browsers. Familiarity with Coup is not required.

## Capabilities and Constraints
Preserve the referenced game's mechanics. Server owns cards, turn state and validation. Players only receive their own hidden cards. Include in-game help. Hosting remains undecided; deliver a locally runnable project.

## Brand Commitments
Cat Coup; cat character designs replacing human characters. Original artwork and concise original interface text, with credit and link to the referenced rules.

## Evidence on Hand
Rules reference: https://www.qugs.org/rules/r131357.pdf. Implementation checklist in BRIEF.md.
